# 🔍 GitHub User Search Application (React)

A modern React application that allows users to search for GitHub profiles using the GitHub API.  
This project demonstrates API integration, state management, conditional rendering, and deployment to production.

Built as part of the **ALX Frontend Engineering Program**.

---

## 🚀 Project Overview

The **GitHub User Search Application** enables users to:
- Search for GitHub users by username
- View basic profile information (avatar, name, profile link)
- Perform advanced searches using filters such as location and repository count
- Experience a responsive and clean user interface
- Access the application live after deployment

This project progressively introduces real-world frontend concepts such as API consumption, environment variables, UI states, and deployment workflows.

---

## 🎯 Learning Objectives

Through this project, I am learning how to:

- Set up and structure a React application using **Vite**
- Consume external APIs using **Axios**
- Handle loading, success, and error states in React
- Implement basic and advanced search features using the **GitHub API**
- Improve UI/UX using **Tailwind CSS**
- Secure sensitive data using environment variables
- Deploy a production-ready React application to **Vercel**

---

## 🛠️ Tech Stack

- **React (Vite)**
- **Axios** – for HTTP requests
- **Tailwind CSS** – for styling
- **GitHub REST API**
- **Vercel** – for deployment
